BEFORE YOU START

出发前，
了解这几件事。

有些选择，提前说清楚更安心。

下载后就能直接玩星露谷吗？＋

星芽是第三方启动器，不包含游戏本体。请先安装你拥有的 Windows 版游戏，再选择对应目录。Steam、Xbox / PC Game Pass 使用官方客户端的当前账号；本地离线模式使用已有、可离线运行的游戏文件，不提供游戏本体下载。

需要安装哪些运行环境？＋

支持 Windows 10 / 11 x64，需要 .NET 10 Desktop Runtime x64 与 Microsoft Edge WebView2 Runtime。引导程序会检测缺失环境，从微软下载并检查签名；安装过程可能需要管理员确认。当前 ZIP 并非包含全部运行环境的免前置版本。

Nexus 免费账号可以直接下载 Mod 吗？＋

无需 API Key 即可通过官方 API 浏览目录、详情和文件列表。Premium 账号可使用自己的 API Key 直下；免费账号需连接本人的 API Key，首次使用时注册 NXM 链接处理，再按 Nexus 官方规则在浏览器完成下载授权，由 NXM 链接交回启动器处理。不会绕过站点登录、付费或下载限制。

AI 会自动上传日志或帮我改文件吗？＋

不会。先在本地筛选、去重并脱敏，由你预览后明确确认发送。可使用自己的厂商密钥或 Ollama 本地模型；费用由所选服务方结算。AI 输出用于辅助判断，建议结合依赖检查与实际测试，不会自动修复或修改 Mod。

SMAPI 和 Mod 安装有哪些注意事项？＋

SMAPI 下载并校验后，仍需运行官方 install on Windows.bat 完成安装。公开 Mod ZIP 可下载安装，但部分社区资源需要登录或访问原站。禁用 Mod 可用于排错；删除 Mod 会直接移除，不保留备份，请确认后操作。

联机需要什么？能和陶瓦互通吗？＋

双方使用星芽联机模块与兼容的游戏、Mod 版本。首次点击安装会下载约 31 MiB 的 EasyTier 核心；房主需在游戏中开好合作农场并准备小屋，加入方在局域网 / IP 入口填写 127.0.0.1。星芽 SG1 邀请码不与陶瓦互通；能否直连取决于网络，必要时由公共节点中转。目前已验证本机双核心 UDP 通信，跨地区真人联机仍需进一步验证。
