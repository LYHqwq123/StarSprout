# 更新记录

## 0.4.0 · 2026-10-14

- 新增 SMAPI 中国国内下载线路，与官方同版本 SHA-256 校验，失败可回退官方线路；下载后准备安装文件。
- 首页新增月份启动日历，成功启动当天以当次主题色圈出日期，支持切换月份与累计次数。
- 首页游戏图片支持自定义和恢复默认，与启动器背景分别保存。
- Mod 列表新增删除，确认后从游戏移除，并保留完整副本与恢复信息。
- 关于页加入作者 GitHub 主页和项目致谢，整理公开源码、许可证及正式发布包。
- 社区、作者原站和 Nexus 网页链接统一使用系统默认浏览器打开；3DM 与 API 直链仍在启动器中下载安装。

## 0.3.1

- 3DM 列表支持直接下载与自动安装，自动识别更新、保留配置、备份与回滚。
- 数据汉化补丁可匹配已有原版后应用；缺少原版时保留缓存并提示。
- Nexus 支持软件内打开 Mod 链接、网页登录、ZIP 与 NXM 下载、下载后安装。
